# Balance / Requirements Sync — Action Items

Generated by comparing `docs/hamlet_havoc_req.md` against the current code. Each
item is self-contained: it names the requirement, what the code does today, the
files/constants to touch, and the concrete change. Section refs (§) point at the
req doc.

Resolved requirement conflicts (decided with the product owner, doc already
updated to match):
- **Fishing attack chance** → §14 governs: **15% sea serpent + 7% kraken**, two
  independent rolls per yield (§26 line updated).
- **Water-predator despawn** → §17.3 governs: persist **one year from spawn**,
  despawn at the start of that same season next year (§15.3 updated).
- **Water-predator movement** → §14 governs: predators **move within water**
  toward the nearest reachable player.
- **Horse upkeep** → §9 governs: **no per-season horse cost**; hay-field capacity
  replaces it. "Mild Winter" now waives **worker** upkeep instead (§16.3 updated).

Confirmed clarifications (doc updated to match):
- §16.0 "years 7-10" was a typo → **years 7-9** (doc fixed). Cadence: Year 1 is
  always a good Misc; years 2-3 are one Attack + one Tax in random order; then each
  rolling 3-year block (4-6, 7-9, 10-12, …) has one Misc + one Tax + one Attack in
  random order.
- §16.1 "Raiding party" "goblin captain" → **Goblin Chief** (`goblinChief`); doc
  fixed.
- **`hay` is no longer a resource.** It must be removed as a stored/tradeable
  resource (value 0, excluded from town trades). Hay fields produce nothing — they
